Subdimensionamento

Estruturas hidráulicas insuficientes, gerando alagamentos frequentes e riscos humanos.

Superdimensionamento

Obras com custo desnecessariamente elevado para o erário ou projeto privado.

Modelos tradicionais assumem estacionariedade climática. O IDFLab incorpora projeções do CLIMBra para antecipar chuvas extremas até 2100.
